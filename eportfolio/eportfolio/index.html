Learning Reflection

What important knowledge and skills did I learn?

I learned how to construct precise, well-conceptualized PowerPoint presentations and enhanced my technical proficiency across various software editing tools. Additionally, I developed skills in visual hierarchy, layout structuring, and content organization to communicate complex ideas effectively.

Which activities or topics were most challenging?

Working with Figma was the most challenging activity because it was my first time using the platform. Navigating its interface, managing frames, and learning its specific UI design tools required a steep learning curve compared to standard presentation tools.

How did I overcome the difficulties?

I overcame these challenges by watching step-by-step video tutorials, studying design templates for inspiration, and engaging in continuous hands-on practice. Taking an iterative approach allowed me to troubleshoot visual layout issues and gradually master the tools.

How will I apply what I learned?

I will apply these skills to design visually engaging presentation decks, UI mockups, and structured digital assets for future academic and professional projects. Combining PowerPoint structure with Figma design tools will allow me to present complex ideas clearly and compellingly.

Course Learning Summary

Overall, this learning experience provided a solid foundation in presentation structure and visual design software. While using Figma for the first time presented a steep learning curve, working through tutorials and experimenting with layouts helped build confidence. Stepping out of comfortable tools like PowerPoint to learn a modern design platform expanded practical skill sets, making it much easier to create professional presentations, UI mockups, and visual assets for future projects.
